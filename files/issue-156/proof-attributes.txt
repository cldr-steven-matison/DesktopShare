Rig: iceberg-demo ns (tabulario iceberg-rest + MinIO), demo.flights = 120,000 rows / 12 monthly

Attributes read off the queued FlowFiles of the QueryIcebergDemo PG after one trigger per processor.

### query=pruned   (QueryFlights: SELECT carrier_code, origin, dest, dep_delay FROM flights WHERE flight_month = '2026-03')
  record.count = 10000
  iceberg.table.name = flights
  iceberg.pushdown.filter = ref(name="flight_month") == "2026-03"
  iceberg.pushdown.columns = carrier_code,origin,dest,dep_delay,flight_month
  iceberg.scan.result.data.files = 1
  iceberg.scan.skipped.data.files = 0
  iceberg.scan.skipped.data.manifests = 11
  → partition pruning at the MANIFEST layer: 11 of 12 manifests never opened, 1 of 12 data
    files planned. skipped.data.files counts only files skipped within scanned manifests,
    which is why it reads 0 here (and ≥1 in the unpartitioned unit-test table).

### query=delayed   (QueryFlights: SELECT * FROM flights WHERE dep_delay > 45 AND carrier_code = 'AA')
  record.count = 2470
  iceberg.table.name = flights
  iceberg.pushdown.filter = (ref(name="dep_delay") > 45 and ref(name="carrier_code") == "AA")
  iceberg.pushdown.columns = flight_id,carrier_code,flight_num,origin,dest,flight_month,dep_delay,distance
  iceberg.scan.result.data.files = 12
  iceberg.scan.skipped.data.files = 0
  iceberg.scan.skipped.data.manifests = 0
  → filter pushed; no file skipped because every monthly file's dep_delay/carrier_code stats
    span the predicate (honest result — stats pruning needs disjoint ranges).
