## [Securing Applications](https://docs.cloudera.com/machine-learning/1.5.5/applications/topics/ml-securing-applications.html)

You can provide access to Applications via either the CDSW_APP_PORT or the CDSW_READONLY_PORT. Any user with read or higher permissions to the project is able to access an application served through either port.

The Monitoring Applications feature allows you to track the CPU and memory usage of deployed applications and access application run logs for troubleshooting purposes.
