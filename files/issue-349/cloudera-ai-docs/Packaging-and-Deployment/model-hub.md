# Using Model Hub

> Canonical URL: https://docs.cloudera.com/machine-learning/1.5.5/model-hub/

Product: machine-learning 1.5.5

## [Using Model Hub](https://docs.cloudera.com/machine-learning/1.5.5/model-hub/topics/ml-use-model-hub.html)

You can easily import the models listed in the Model Hub into the Registered Models page and then deploy it using the Cloudera AI Inference service. This streamlines the workflow of developers working on AI use cases by simplifying the process of discovering, deploying, and testing models.

### [Role-based authorization in Model Hub](https://docs.cloudera.com/machine-learning/1.5.5/model-hub/topics/ml-model-hub-authorization.html)

Model Hub implements role-based access control.

### [Allowlist of URLs for Model Hub in air-gapped installations](https://docs.cloudera.com/machine-learning/1.5.5/model-hub/topics/ml-model-hub-air-gap-installation.html)

For air-gapped installations using a non-transparent proxy, you must add the following URLs to your firewall allowlist to ensure the Model Hub functions correctly and to maintain access to the latest model catalogs.

### [Importing models from NVIDIA NGC](https://docs.cloudera.com/machine-learning/1.5.5/model-hub/topics/ml-import-model-nvidia-ngc.html)

You can import the NVIDIA NGC Catalog models listed in the Model Hub page and deploy it from the Registered Models page.

### [Importing models from Hugging Face (Technical Preview)](https://docs.cloudera.com/machine-learning/1.5.5/model-hub/topics/ml-import-model-hugging-face.html)

You can import the Hugging Face models listed on the Model Hub page into your Model Registry. If your preferred model is not listed on the Model Hub page, you can import it from the Registered Models page. After you import the model, the newly imported model will be listed on the Registered Models page.

### [Downloading and uploading Model Repositories for an air-gapped environment](https://docs.cloudera.com/machine-learning/1.5.5/model-hub/topics/ml-models-in-air-gapped-environment.html)

An air-gapped environment is physically isolated from the internet and external networks, preventing the transmission or reception of data online. As a result, enabling the download of Model Repositories in such environments requires the Administrator to perform additional steps.
