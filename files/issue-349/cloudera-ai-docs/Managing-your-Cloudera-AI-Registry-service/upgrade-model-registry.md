## [Cloudera AI Registry upgrade](https://docs.cloudera.com/machine-learning/1.5.5/upgrade-model-registry/topics/ml-model-registry-upgrade.html)

Cloudera AI Registry can be upgraded in place using Helm Upgrade on the existing release within the same namespace in Cloudera AI 1.5.5 SP3 and higher releases.

### [Upgrading Cloudera AI Registry using the UI](https://docs.cloudera.com/machine-learning/1.5.5/upgrade-model-registry/topics/ml-upgrading-cloudera-ai-registry-using-ui.html)

Upgrade Cloudera AI Registry through the Cloudera AI user interface to deploy higher software versions on ready-state environments.

### [Upgrading Cloudera AI Registry in 1.5.5 SP2 CHF1 and lower releases](https://docs.cloudera.com/machine-learning/1.5.5/upgrade-model-registry/topics/ml-upgrading-cloudera-ai-registry-using-cli.html)

Upgrade Cloudera AI Registry by provisioning a new parallel instance, synchronizing model data, and removing the legacy environment.
