## [Cloudera Copilot Overview](https://docs.cloudera.com/machine-learning/1.5.5/manage-cloudera-copilot/topics/ml-copilot-intro.html)

Learn how to configure and use Cloudera Copilot with Cloudera AI Inference service and Amazon Bedrock models.

### [Configuring Cloudera AI Inference service and Amazon Bedrock to set up Cloudera Copilot](https://docs.cloudera.com/machine-learning/1.5.5/manage-cloudera-copilot/topics/ml-cloudera-copilot-prereqs.html)

To use Cloudera Copilot, as a Site Administrator, set up Cloudera AI Inference service model endpoints or configure the credentials in Amazon Bedrock depending on where you want to deploy your custom model.

### [Configuring Cloudera Copilot](https://docs.cloudera.com/machine-learning/1.5.5/manage-cloudera-copilot/topics/ml-setup-cloudera-copilot.html)

After setting up credentials, you must make configuration changes in the Cloudera AI UI before using Cloudera Copilot.
