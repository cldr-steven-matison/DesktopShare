## [Custom AMP Catalog](https://docs.cloudera.com/machine-learning/1.5.5/manage-amp/topics/ml-amp-custom-amp-catalog.html)

An AMP catalog is a collection of AMPs that can be added to a workbench as a group. Cloudera AI ships with the Cloudera AMP catalog, containing AMPs developed by Cloudera Fast Forward Labs, but you can also create and add your own catalog, containing AMPs developed by your organization.

## [Adding a catalog](https://docs.cloudera.com/machine-learning/1.5.5/manage-amp/topics/ml-amp-add-catalog.html)

The collection of AMPs available to end users can draw from one or more sources. For example, you might have an internal company catalog in addition to the default Cloudera catalog. The catalog must be provided with a catalog file and one or more project metadata YAML files.

## [Catalog File Specification](https://docs.cloudera.com/machine-learning/1.5.5/manage-amp/topics/ml-amp-catalog-spec.html)

The Catalog file is a YAML file that contains descriptive information and metadata for the displaying the AMP projects in the Project Catalog.
