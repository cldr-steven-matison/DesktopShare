# Built-in Cloudera AI Visualizations

> Canonical URL: https://docs.cloudera.com/machine-learning/1.5.5/visualizations/

Product: machine-learning 1.5.5

## [Built-in Cloudera AI Visualizations](https://docs.cloudera.com/machine-learning/1.5.5/visualizations/topics/ml-native-visualizations.html)

You can use built-in Cloudera AI tools to create data visualizations including simple plots, saved images, HTML and iFrame visualizations, and grid displays.

### [Simple Plots](https://docs.cloudera.com/machine-learning/1.5.5/visualizations/topics/ml-simple-plots.html)

Cloudera AI supports using simple plot to create data visualizations.

### [Saved Images](https://docs.cloudera.com/machine-learning/1.5.5/visualizations/topics/ml-saved-images.html)

You can display images within your reports.

### [HTML Visualizations](https://docs.cloudera.com/machine-learning/1.5.5/visualizations/topics/ml-html-visualizations.html)

Your code can generate and display HTML in Cloudera AI.

### [IFrame Visualizations](https://docs.cloudera.com/machine-learning/1.5.5/visualizations/topics/ml-iframe-visualizations.html)

Most visualizations require more than basic HTML. Embedding HTML directly in your console also risks conflicts between different parts of your code. The most flexible way to embed a web resource is using an IFrame.

### [Grid Displays](https://docs.cloudera.com/machine-learning/1.5.5/visualizations/topics/ml-grid-displays.html)

Cloudera AI supports built-in grid displays of DataFrames across several languages.

### [Documenting Your Analysis](https://docs.cloudera.com/machine-learning/1.5.5/visualizations/topics/ml-documenting-your-analysis.html)

Cloudera AI supports Markdown documentation of your code written in comments.

## [Cloudera Data Visualization for Cloudera AI](https://docs.cloudera.com/machine-learning/1.5.5/visualizations/topics/ml-cdv-for-cml.html)

Cloudera Data Visualization enables you to explore data and communicate insights across the whole data lifecycle by using visual objects. The fast and easy self-service data visualization streamlines collaboration in data analytics through the common language of visuals.
